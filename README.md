# Farrowing Date Calculator
Live at: www.allenandemily.com/kunekune-farrowing-calculator 

KuneKune pigs have a gestation period that is easy to remember. It's 3 months, 3 weeks, and 3 days (approximately 114 days). KuneKunes typically farrow between days 112–116. This calculator removes the need to do the math yourself.

## Features

- **Two calculation modes:**
  - Calculate farrowing date from breeding date
  - Calculate breeding date from target farrowing date

- **Interactive timeline** showing key milestones throughout the pregnancy:
  - Heat checks
  - Nesting behavior observation
  - Farrowing area preparation
  - Expected farrowing window

- **Additional tools:**
  - Print-friendly results
  - Copy to clipboard functionality
  - Optional sow name tracking

- **Self-contained:** All code is in a single HTML file that can be embedded on any web page. Designed for Ghost CMS HTML card embeds, but should work anywhere.
